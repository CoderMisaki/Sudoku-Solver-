## 2024-05-15 - Dynamic Status Announcements and Focus Management
**Learning:** Custom UI components built with `div` elements, such as a Sudoku grid, require manual keyboard management. Relying solely on visual classes like `.selected` is insufficient for accessibility and keyboard navigation. Furthermore, status updates (like errors or completions) injected into a div must use `aria-live="polite"` to be announced by screen readers without interrupting the user.
**Action:** When creating grid-like custom components, always implement a roving `tabindex` (toggling `tabIndex` between `-1` and `0`) to correctly sync focus with the active element. Explicitly call `.focus({ preventScroll: true })` on the newly active element to trigger native focus indicators (`:focus-visible`) and synchronize with screen reader cursors without unintended scrolling. Always add `aria-live="polite"` to dynamically updating text status containers.
