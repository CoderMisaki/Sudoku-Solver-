## 2026-05-15 - Add Content Security Policy
**Learning:** The application lacked a Content Security Policy (CSP), making it potentially vulnerable to XSS and data injection attacks if input validation were ever compromised. While input was correctly validated, adding a CSP provides essential defense in depth.
**Action:** Implemented a restrictive CSP in `index.html` using a meta tag. Allowed `self` and `unsafe-inline` for scripts/styles to accommodate Tailwind CDN compilation, while strictly limiting `connect-src` and `default-src` to prevent unauthorized resource loading or data exfiltration.
