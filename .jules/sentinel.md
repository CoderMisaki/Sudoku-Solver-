## 2026-05-24 - CSP and SRI Enhancement
**Vulnerability:** Use of external script from CDN without Subresource Integrity check and lack of Content Security Policy, making the application vulnerable to XSS and third-party tampering.
**Learning:** Adding a strict `default-src 'self'` CSP must be done carefully in a vanilla JS app using Tailwind CDN. We need `'unsafe-inline'` and `'unsafe-eval'` to allow Tailwind's runtime script to generate styles, which somewhat reduces the effectiveness of the CSP against XSS, but is required for this specific architecture unless a build step is introduced. SRI implementation was straightforward but critical for CDN scripts.
**Prevention:** Always verify external resources used in an application before enforcing a restrictive CSP, and understand the trade-offs between security policies and development/architecture choices like using a runtime CSS-in-JS CDN.
